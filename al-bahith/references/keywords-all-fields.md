# Keyword lists for "all fields" runs

Use these when the user names no field. Pick a rotation of 12–20 keywords for the run, show them to the user,
and wait for an OK before scanning. Each run, prefer keywords not used in recent runs (check the
`keywords` stored in `<data dir>/runs/*/final.json`, or the «كلمة البحث» column of the Excel file).

Meta Ad Library matches words in the ad text. Short, common words used in ads work best. For Gulf countries, mix
Arabic and English, because many local ads are bilingual.

## Field-specific runs
When the user names a field (for example "عيادات أسنان"), build 8–15 keywords for that field yourself:
- the Arabic name and its common dialect forms (عيادة أسنان، تقويم، تبييض أسنان، زراعة أسنان)
- the English words used in that country's ads (dental clinic, braces, teeth whitening, veneers)
- service words and offer words for that field (عرض تنظيف أسنان، خصم ابتسامة هوليود)
Show them as a numbered list and ask the user to approve, add or remove some before running.
